# Contributing

Useful contributions:

- a defect class the matrices or checklists miss, with a generic example
- corrections where guidance is wrong or unclear
- matrix rows for common SaaS features not covered yet (subscriptions, SSO, webhooks)

Please keep everything generic and public-safe:

- no client or company names, internal URLs, screenshots of real systems, or real defect tickets
- no credentials or tokens, including expired ones
- no proprietary test cases; describe the class of defect instead

Keep claims modest. These resources help find defects; they do not certify a system as secure or correct.

For the example, `python3 examples/demo-api/demo_api.py` and `python3 examples/demo-api/probe.py` should still run and report the documented defects after your change.
